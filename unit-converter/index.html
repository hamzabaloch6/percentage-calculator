How to Use the Unit Converter

  1. Select the type of conversion.
  2. Enter the value you want to convert.
  3. Select the original unit.
  4. Select the unit you want to convert to.
  5. Click the Convert button.

Supported Conversions

This calculator supports several common unit conversions including length, weight, temperature, area, volume and time.

Examples

Length: 1 kilometer = 1000 meters.

Weight: 1 kilogram = 1000 grams.

Temperature: 0°C = 32°F.

Time: 1 hour = 60 minutes.
